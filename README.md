# Proyecto-Salon

Sistema para apoyar a salones en la organización de su croquis, control de meseros y eventos.

El objetivo es:
- Tener un control inventarial.
- Organizar mesas y personal de forma más flexible y legible.
- Facilitar la gestión del capitán de meseros.
- Obtener comentarios de meseros y asistentes a eventos.
- Realizar un análisis socioeconómico y de sentimientos para evaluar la experiencia del salón y el tipo de público esperado.
